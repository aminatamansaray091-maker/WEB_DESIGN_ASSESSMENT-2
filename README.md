# Explore Salone

Explore Salone is a responsive five-page tourism website for discovering destinations, activities and culture in Sierra Leone. It is built with HTML5, CSS3 and vanilla JavaScript.

## Project structure

- `index.html` - Home
- `destinations.html` - Destination search and category filters
- `activities.html` - Tourism activities
- `about.html` - Country and mission information
- `contact.html` - Contact information and validated demo form
- `css/style.css` - Shared responsive styles
- `js/script.js` - Shared navigation, filtering and form behavior

## Run locally

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension if it is not already installed.
3. Right-click `index.html` and choose **Open with Live Server**, or start Live Server from the VS Code status bar.
4. Use the navigation to visit all pages.

The page can also be opened directly by double-clicking `index.html`, although Live Server is recommended.

## Images

The site uses royalty-free Unsplash image URLs for convenient previewing. Download preferred images and replace each URL with a relative file under an `images/` folder if the project needs to run completely offline.

## Contact form

The contact confirmation is a client-side demonstration only. Actual delivery requires a backend, email API or form-processing service; the submitted details are not emailed or saved by this project.
